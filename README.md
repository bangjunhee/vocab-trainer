# 📚 영단어 랜덤 트레이너

> **단어장 순서를 외우는 게 아니라, 단어 자체를 외우기 위한 브라우저 기반 영단어 학습기**

영단어장을 위에서부터 반복해서 보다 보면 뜻보다 **위치와 순서**를 먼저 외우게 되는 문제가 있습니다.  
이 프로젝트는 단어를 매번 무작위로 섞고, 틀린 단어를 더 자주 다시 출제해서 **순서 의존 없이 기억하도록** 만든 개인용 영단어 트레이너입니다.

별도 설치나 서버 없이 `index.html` 하나로 동작하며, GitHub Pages에 올려두면 PC·태블릿·휴대폰 브라우저에서 바로 사용할 수 있습니다.

---

## ✨ 주요 기능

### 🎲 랜덤 테스트

매 세션마다 단어 순서를 무작위로 섞어서 출제합니다.

지원하는 문제 유형:

- **영어 → 한국어** 객관식
- **한국어 → 영어** 객관식
- **한국어 → 영어** 직접 타이핑
- 위 유형을 랜덤하게 섞는 **혼합 모드**

객관식은 키보드 `1` ~ `4`, 다음 문제는 `Enter`로 빠르게 진행할 수 있습니다.

---

### 🧠 오답 가중 출제

모든 단어가 똑같은 확률로 나오지 않습니다.

테스트에서 틀리거나 플래시카드에서 `몰라요`로 평가한 단어는 **이후 랜덤 테스트에서 더 자주 출제**됩니다.

즉,

> **아는 단어는 덜 보고, 모르는 단어는 더 본다.**

세션이 끝나면 틀린 단어만 모아 바로 재시험할 수도 있습니다.

---

### 🃏 플래시카드

단어를 보고 뜻을 떠올린 뒤 카드를 뒤집어 확인할 수 있습니다.

각 단어를 다음 세 단계로 평가합니다.

- `몰라요`
- `애매`
- `알아요`

평가 결과는 이후 출제 빈도에 반영됩니다.

---

### ➕ 단어 직접 추가

TXT 파일을 매번 수정할 필요가 없습니다.

영단어 책 하루치인 **40~50개 정도를 사이트에서 한꺼번에 붙여넣고 저장**할 수 있습니다.

권장 형식:

```text
laudable	칭찬할 만한
meddle	간섭하다
take ~ into account	고려하다
```

아래 형식도 인식합니다.

```text
laudable | 칭찬할 만한
meddle = 간섭하다
take ~ into account    고려하다
```

입력 전에 인식된 단어와 개수를 미리 확인할 수 있으며, 저장된 단어는 기존 단어장과 합쳐져 모든 학습 기능에서 사용됩니다.

---

### 🎯 원하는 범위만 테스트

랜덤 테스트의 출제 범위를 선택할 수 있습니다.

| 범위 | 설명 |
|---|---|
| 전체 단어 | 기본 단어 + 직접 추가한 단어 |
| 직접 추가한 단어 | 사용자가 추가한 단어만 |
| 가장 최근 추가 묶음 | 마지막으로 저장한 하루치 단어만 |
| 오늘 추가한 단어 | 오늘 저장한 단어만 |
| 기본 검수 단어 | 처음 포함된 기본 단어만 |

새 단어를 저장한 직후 **`최근 묶음 바로 테스트`**를 누르면 방금 공부한 하루치만 바로 시험할 수 있습니다.

---

### 📊 학습 기록

사이트에서 다음 기록을 확인할 수 있습니다.

- 누적 학습 단어
- 정답률
- 오답 단어
- 단어별 정답/오답 기록
- 약한 단어
- 직접 추가한 단어 수

전체 단어 목록에서 검색하거나 **약한 순**으로 정렬할 수도 있습니다.

---

### 💾 브라우저 자동 저장

추가한 단어와 학습 기록은 브라우저의 `localStorage`에 저장됩니다.

따라서 같은 브라우저에서 같은 사이트 주소로 접속하면 페이지를 닫았다 다시 열어도 기록이 유지됩니다.

> [!IMPORTANT]
> 데이터는 GitHub 저장소에 저장되는 것이 아닙니다.  
> 다른 PC, 휴대폰, 브라우저로 자동 동기화되지 않습니다.

기기를 바꾸거나 브라우저 데이터를 삭제할 경우를 대비해 **백업 내보내기 / 불러오기** 기능을 제공합니다.

---

## 🚀 사용 방법

### 1. 바로 실행

`index.html`을 다운로드한 뒤 브라우저로 열면 됩니다.

```text
index.html
```

다만 실제로 계속 사용할 목적이라면 아래처럼 **GitHub Pages에 올려두는 방식**을 권장합니다.

---

## 🌐 GitHub Pages로 배포하기

### 1. GitHub 저장소 만들기

GitHub에서 새 Repository를 생성합니다.

예:

```text
vocab-trainer
```

### 2. `index.html` 업로드

저장소 최상위 경로에 `index.html`을 올립니다.

구조는 이렇게 단순하면 됩니다.

```text
vocab-trainer/
├── index.html
└── README.md
```

### 3. GitHub Pages 활성화

저장소에서:

```text
Settings
→ Pages
→ Build and deployment
→ Source: Deploy from a branch
→ Branch: main
→ Folder: / (root)
→ Save
```

### 4. 사이트 접속

GitHub 아이디가 `yourname`, 저장소가 `vocab-trainer`라면 보통 다음 주소로 접속합니다.

```text
https://yourname.github.io/vocab-trainer/
```

이 주소를 Chrome 즐겨찾기나 홈 화면에 추가해두면 일반 사이트처럼 사용할 수 있습니다.

## 📖 추천 학습 루틴

하루에 영단어 책 한 단원을 공부한다고 가정하면:

```text
1. 단어 추가/관리
        ↓
2. 오늘 단어 40~50개 붙여넣기
        ↓
3. 저장
        ↓
4. 최근 묶음 바로 테스트
        ↓
5. 혼합 문제 풀이
        ↓
6. 오답만 재시험
        ↓
7. 플래시카드로 최종 확인
        ↓
8. 며칠 뒤 전체 단어 랜덤 테스트
```

핵심은 **새 단어만 단기적으로 반복한 뒤, 기존 단어와 섞어서 다시 테스트하는 것**입니다.

## 🗃️ 백업과 복원

### 백업

`단어 추가/관리` → **백업 내보내기**

추가 단어와 학습 기록이 JSON 파일로 저장됩니다.

### 복원

`단어 추가/관리` → **백업 불러오기**

이 사이트에서 내보낸 JSON 백업 파일을 선택하면 기존 데이터를 복원할 수 있습니다.

> [!WARNING]
> 백업 불러오기는 현재 브라우저에 저장된 데이터를 백업 파일의 내용으로 교체합니다.

---

## 🔒 데이터와 개인정보

이 프로젝트에는 별도의 서버나 회원가입 기능이 없습니다.

현재 구조에서는:

- 추가한 단어
- 정답/오답 기록
- 플래시카드 평가
- 학습 통계

가 모두 **사용자의 브라우저 내부에만 저장**됩니다.

---

## ⚠️ 현재 제한사항

직접 추가한 단어는 입력한 내용을 그대로 저장합니다.

따라서 현재 버전에는 다음 기능이 없습니다.

- 영단어 철자 자동 교정
- 한국어 뜻 자동 검수
- 온라인 사전과 자동 대조
- 여러 기기 간 자동 동기화
- 사용자 계정/로그인

중요한 단어를 대량 추가한 경우에는 철자와 뜻을 한 번 확인하는 것이 좋습니다.

---

## 🛠️ 기술 구성

복잡한 빌드 과정 없이 최대한 단순하게 유지합니다.

```text
HTML
CSS
Vanilla JavaScript
localStorage
```

별도 프레임워크, 데이터베이스, 백엔드 서버가 필요하지 않습니다.

---

## 🎯 프로젝트 목적

이 프로젝트의 목적은 단순합니다.

> **“단어장의 순서를 기억해서 맞히는 것”과  
> “단어의 뜻을 실제로 기억하는 것”을 분리한다.**

그래서 다음 원칙을 중심으로 설계했습니다.

1. 출제 순서는 계속 섞는다.
2. 같은 단어도 여러 방식으로 묻는다.
3. 틀린 단어는 다시 자주 보여준다.
4. 새 단어와 예전 단어를 섞는다.
5. 단어 추가 과정은 최대한 귀찮지 않게 만든다.
